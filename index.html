About

From breaking systems to building secure ones

I'm a DevSecOps Engineer at Seclogic Technologies in Noida. I build CI/CD pipelines with security scanning built in, enforce Kubernetes policies as code, and automate cloud infrastructure on AWS and GCP.

I started on the offensive side, with vulnerability assessment, penetration testing and OWASP Top 10 work as a Cyber Security Analyst Intern. Today I work across Jenkins, GitLab, Docker, Kubernetes, Terraform and Ansible. I hold an MCA from GLA University, Mathura.

Security is a stage in the pipeline, not a review after it.

  1. 01

    Shift left

    Catch code and image vulnerabilities in the pipeline, before deployment.

  2. 02

    Policy as Code

    Deployment standards are written as policies and enforced automatically.

  3. 03

    Automate infrastructure

    Environments are provisioned with Terraform, not by hand.

  4. 04

    Observe what runs

    Metrics and logs through Prometheus, Grafana and the ELK Stack.
